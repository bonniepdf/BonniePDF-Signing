# BonniePDF Signing

Sign PDFs generated by BonniePDF in .NET, TypeScript, or JavaScript. Add a visible signature box or sign invisibly, choose a PAdES baseline profile from B-B through B-LTA, and use an RFC 3161 timestamp authority when the profile requires it. Both packages support RSA and ECDSA with PEM or PKCS#12 credentials.

**Signing is included at no extra charge with every paid BonniePDF Professional or Enterprise licence.** Both packages are available for free non-production evaluation. [See pricing and licensing](https://www.bonniepdf.dev/pricing).

| Runtime | Package | Guide |
| --- | --- | --- |
| .NET | [`BonniePDF.Signing` on NuGet](https://www.nuget.org/packages/BonniePDF.Signing) | [.NET signing guide](https://www.bonniepdf.dev/features/dotnet/signing) |
| TypeScript and JavaScript | [`@bonniepdf/signing` on npm](https://www.npmjs.com/package/@bonniepdf/signing) | [TypeScript signing guide](https://www.bonniepdf.dev/features/typescript/signing) |

## Install

Add both packages in a .NET project that generates and signs PDFs.

```sh
dotnet add package BonniePDF
dotnet add package BonniePDF.Signing
```

Install both packages in a TypeScript or JavaScript project that generates and signs PDFs.

```sh
npm install @bonniepdf/core @bonniepdf/signing
```

## Demos

Both runtimes include a signed services agreement and a sealed fire safety certificate.

| Demo | Signature | What it shows |
| --- | --- | --- |
| Services agreement | Visible, PAdES B-B | The signer places the signature in a named box located by the layout snapshot. |
| Fire safety certificate | Visible, PAdES B-LT | The document carries a timestamp and embedded validation data for offline verification. |

```powershell
# TypeScript (from typescript/signing)
tsx examples/signed-agreement.ts agreement.pdf
tsx examples/sealed-certificate.ts certificate.pdf

# .NET: writes both, with the rest of the sample set
dotnet run --project dotnet/BonniePDF.Signing.SampleGen -- signed-samples
```

The demos generate temporary signing credentials and run offline. For production signing, supply your own signing credentials and the URL of your timestamp authority when needed.

## Build and test

Run the TypeScript commands from the BonniePDF pnpm workspace root, where `@bonniepdf/core` is available as a workspace dependency.

```sh
pnpm --filter @bonniepdf/signing typecheck
pnpm --filter @bonniepdf/signing test
pnpm --filter @bonniepdf/signing build
```

Run the .NET commands from this repository. Tests and sample generation use the core project to generate PDFs to sign.

```sh
dotnet test dotnet/BonniePDF.Signing.Tests/BonniePDF.Signing.Tests.csproj
dotnet pack dotnet/BonniePDF.Signing/BonniePDF.Signing.csproj -c Release -p:GeneratePackageOnBuild=false
```
